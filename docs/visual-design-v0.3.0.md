# v0.3.0 visual direction

This refresh keeps the orbital logo and the existing README information architecture, but changes the supporting language from space hardware to an operational evidence board. The product is a developer control layer, so the visual system now emphasizes routing, guardrails and acceptance rather than spectacle.

Design dials: variation 6, motion 3, density 5. The assets are static repository illustrations, not an interactive web redesign. The cover uses deterministic SVG so version strings, route examples and labels remain exact and auditable.

Palette:

- Graphite `#141615` and panel `#20231f` for the control surface.
- Warm paper `#e9e3d7` and heading `#f2eee5` for readable contrast.
- Safety orange `#e6a15d` as the single routing accent.
- Sage `#c7d5b7` for accepted or verified states.

Assets:

- `assets/release-v0.3.0.svg` is the GitHub cover: dark editorial type on the left, an evidence board on the right, and the A/B/C routing summary.
- `assets/terminal-preview.svg` is a compact, illustrative CLI preview using verified v0.3.0 examples.
- Eight files under `assets/interfaces/` are generated by `scripts/render_interface_assets.py` and share the same palette, numbered evidence rows and route/guard/verify labels.
- `assets/logo/mission-control.svg` remains unchanged so the product mark stays recognizable across the redesign.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
