# v0.5.0 visual direction

This stable release keeps the v0.4.1 visual system unchanged. Only the release identity changes, and the cover drops the pre-release label that the v0.4.2 candidates carried.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels are updated to `0.5.0`.

Assets:

- `assets/release-v0.5.0.svg` is the current GitHub cover.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.5.0 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
