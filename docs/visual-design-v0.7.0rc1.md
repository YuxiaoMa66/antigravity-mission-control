# v0.7.0rc1 visual direction

This pre-release keeps the visual system unchanged. Only the release identity changes.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels are updated to `0.7.0rc1`.

Assets:

- `assets/release-v0.7.0rc1.svg` is the current GitHub cover.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.7.0rc1 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
