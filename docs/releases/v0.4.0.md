# v0.4.0: Codex and Claude Code

Mission Control's Skill now runs in Claude Code as well as Codex. The `agy-mc` runtime is unchanged; the Skill wording is host-neutral and the installers know both hosts.

- One Skill, two hosts. The orchestrating agent is called the host agent; it owns scope, approvals and acceptance.
- `npx antigravity-mission-control@latest install` detects `~/.codex` and `~/.claude`. Choose explicitly with `--host codex|claude|all`; `agy-mc skill` accepts the same flag.
- Claude Code installs go to `${CLAUDE_CONFIG_DIR:-~/.claude}/skills/antigravity-mission-control` with backups in `skill-backups/` beside it. Existing Codex installs, paths and `CODEX_HOME` behavior are unchanged.
- `references/host-notes.md` covers the few real differences: roster choice through `AskUserQuestion`, `--background` with bounded `wait`, a minimal permission allowlist, and skill discovery.
- `agy-mc doctor` warns when an installed Skill is older than the CLI.

Upgrade with `npx antigravity-mission-control@latest update`, then restart Codex or start a new Claude Code session. Routing, signed approvals and worker execution behave as in v0.3.1.
