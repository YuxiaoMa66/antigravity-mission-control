# v0.3.1: Coordinated stable handoff

This patch release is available from the GitHub source tag `v0.3.1`, the GitHub Release, and the public npm package `0.3.1`.

- Correct the copy-ready agent handoff to use the published npm bootstrapper instead of a stale Git-source command.
- Pin reproducible installation examples to `@0.3.1` and `v0.3.1`.
- State the Codex acceptance boundary explicitly: AGY workers execute only inside the approved scope.
- Synchronize Python, npm, CLI, bundled Skill checks, release assets and bilingual documentation.
- Remove the obsolete npm `next` distribution tag; the stable `latest` tag points to `0.3.1`.

This is a packaging and documentation correction release. The Flash-first routing behavior introduced in v0.3.0 is unchanged.

Validation includes the Python and npm test suites, bundled Skill synchronization, interface-asset checks, package dry-run, isolated installer smoke checks, GitHub tag verification and npm registry verification.
