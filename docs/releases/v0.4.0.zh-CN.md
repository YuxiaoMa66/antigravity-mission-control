# v0.4.0：Codex 与 Claude Code 通用

Mission Control 的 Skill 现在既能在 Codex 中使用，也能在 Claude Code 中使用。`agy-mc` 运行时保持不变；Skill 文案改为与宿主无关，两个安装器也都认识这两个宿主。

- 一份 Skill，两个宿主。负责编排的 agent 统称宿主 agent，由它掌管范围、批准和验收。
- `npx antigravity-mission-control@latest install` 会检测 `~/.codex` 与 `~/.claude`。也可以用 `--host codex|claude|all` 明确指定；`agy-mc skill` 支持同一参数。
- Claude Code 的安装位置是 `${CLAUDE_CONFIG_DIR:-~/.claude}/skills/antigravity-mission-control`，备份放在旁边的 `skill-backups/`。已有 Codex 安装、路径和 `CODEX_HOME` 行为不变。
- `references/host-notes.md` 只记录真正的差异：用 `AskUserQuestion` 选择阵容、`--background` 配合有时限的 `wait`、最小权限白名单，以及 Skill 发现方式。
- `agy-mc doctor` 会在已安装 Skill 比 CLI 旧时给出警告。

升级方式：`npx antigravity-mission-control@latest update`，然后重启 Codex 或新开一个 Claude Code 会话。路由、签名批准和 worker 执行行为与 v0.3.1 一致。
