# v0.4.1：Codex 与 Claude Code 加固

v0.4.0 的补丁版本：修复 npm 安装器的两个边界情况，并收紧 Claude Code 的宿主说明。路由、签名批准和 worker 执行行为不变。

- 找不到托管 Skill 时，`npx antigravity-mission-control uninstall` 会重新移除托管运行环境和 CLI 链接。v0.4.0 会报 "No supported host detected" 后退出，把它们留在原地。
- 与 Codex 无关的另一个宿主的配置目录如果是指向 HOME 之外的符号链接，不再阻断 `status`。
- Claude Code 宿主说明现在只建议为只读子命令（`usage`、`doctor`、`models`、`policy`、`select`、`status`、`result`、`wait`）添加白名单规则。之前建议的 `Bash(agy-mc *)` 还会自动放行 `approve`、`run` 和 `workspace --grant`。每条 `agy-mc` 命令应单独作为一次 Bash 调用，沙箱里的状态写入应放进 `sandbox.filesystem.allowWrite`。

升级方式：`npx antigravity-mission-control@latest update`，然后新开一个 Claude Code 会话或重启 Codex。验证：Python 与 npm 测试套件、内置 Skill 同步、界面资产检查、包 dry-run，并且这两个问题在修复前已在已发布的 0.4.0 包上复现。
