# v0.1.0a1 — Mission Control online

First public Alpha candidate.

## Highlights

- Signed, expiring approvals bound to the exact model, workspace, prompt hash, mode and permission profile.
- Atomic OS-level editing lock shared across foreground and background workers.
- Cancellation confirmation with TERM grace period and KILL escalation.
- Sanitized live quota terminal and JSON schema.
- Recoverable Codex Skill install, update and uninstall from Python.
- Dependency-free npm bootstrap with English and Chinese terminal UI.
- Bilingual README, installation, reference and release documentation.

## Validation

All Python and Node black-box tests use fake AGY and isolated HOME/workspace/state paths. A separate read-only smoke validates the installed AGY CLI and live `/usage` contract.

## Alpha limits

- Legacy boolean approval flags remain for migration.
- HMAC proves local manifest integrity, not human identity.
- macOS and Linux only; the edit lock uses `flock`.
- No claim of statistical or security certification.
