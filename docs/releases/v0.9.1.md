# v0.9.1

[简体中文](v0.9.1.zh-CN.md)

- AGY 1.5.9 lists Gemini 4 Neon, and Google's model documentation marks Gemini 4 Argon, Gemini 3.8 Flash and GPT-OSS 120B for removal on 2026-11-30. B planning and review now prefer Neon High, then Carbon High, then Argon High while it remains listed. Claude Opus stays available as the per-role alternative.
- Wherever A or B falls back from Hydrogen and Flash to another Gemini High model, it uses the same Neon, Carbon, Argon order instead of slug order.
- Scouting and implementation stay on Hydrogen in A and B, and C keeps Hydrogen High for every role.
- Orchestrator slugs (`gemini-pro-orchestrator*`) are never proposed automatically. They pair a planner and an executor inside one AGY conversation with a fixed reasoning budget, and run only when the user pins one.
- Verified on 2026-11-24: `scripts/real_agy_check.py` from the release commit against AGY 1.5.16 with `gemini-4-hydrogen-high`: one full run, 19/19. A foreground run with `gemini-4-neon-high` also passes.
