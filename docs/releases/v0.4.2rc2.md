# v0.4.2rc2: Guard fixes for the module split (pre-release)

The second release candidate of the `cli.py` module split introduced in v0.4.2rc1. A review of rc1 found gaps in the guards, and this candidate closes them. Routing and the Skill text are unchanged. npm version: `0.4.2-rc.2`.

- A failed background worker is no longer reported as a success. Before, a run that failed (for example because a permission was soft-denied) was labeled `done_with_warnings` with exit 0 whenever AGY's stderr contained that status text.
- Broad directories are refused as workspaces. Ancestors of your home directory, such as `/Users`, and the system temp roots can no longer be trusted, approved or run in. Use a project directory inside them instead.
- Background jobs no longer hang in `starting` when the launcher dies early, and a cancel issued during launch now wins over the launcher.
- `agy-mc skill uninstall` now refuses a directory that agy-mc did not install unless you pass `--force`, like install and update already did. The npm `uninstall` checks every target before it changes anything, so it cannot stop halfway.

Try it with `npx antigravity-mission-control@next install`, or `python3 -m pip install "git+https://github.com/YuxiaoMa66/antigravity-mission-control.git@v0.4.2rc2"`. Stable remains v0.4.1 and `@latest` does not move. Validation: 51 Python tests and 13 npm tests; each fix adds a regression test that failed before the fix.
