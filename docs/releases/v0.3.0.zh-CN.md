# v0.3.0：Flash 优先路由

本版本已通过 GitHub 源码 tag `v0.3.0` 提供。npm registry 发布和 GitHub Release 不包含在本次操作中。

- A 方案改为轻量和成本优先，按角色风险优先选择合适强度的 Gemini Flash。
- B 方案保持质量优先，但 implementer 按 Flash High → Medium → Low 顺序选择可用模型，之后才回退到 Pro High 或 Claude；GPT 模型放在最后，并尽量保留跨模型家族审核。
- C 方案沿用 B 的质量目标，但所有 AGY 角色统一使用最新的 Gemini Flash High。
- 精确模型 slug 仍由批准清单绑定；Gemini 非 High 的实际执行仍需单独确认。
- 视觉系统更新为操作证据风格：石墨底、暖白面板和单一安全橙路由强调色。
- 内置 Skill 与仓库规范源及 v0.3.0 路由规则保持同步。
