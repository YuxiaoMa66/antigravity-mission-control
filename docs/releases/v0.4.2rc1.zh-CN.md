# v0.4.2rc1：模块拆分（预发布）

一次内部重构的预发布版本。1938 行的 `antigravity_mission_control/cli.py` 被拆分为多个模块，`cli.py` 只保留 `doctor`、参数解析和 `main`。路由、签名批准、worker 执行和 Skill 均不变，根命令与所有子命令的 `agy-mc --help` 输出逐字节一致。npm 版本号：`0.4.2-rc.1`。

- 新模块为 `common`、`routing`、`workspace`、`jobstore`、`approvals`、`usage`、`skill` 和 `jobs`，分层依赖，没有循环导入。
- 后台 worker 仍按路径重新启动，而不是使用 `-m`。worker 的工作目录是你的项目，`-m` 会把它放到 `sys.path` 最前面，项目里的 `json.py` 之类文件就可能在 worker 内顶替标准库。`cli.py` 保留了一小段 `__package__` 垫片，使它仍可作为脚本运行。

试用方式：`npx antigravity-mission-control@next install`，或 `python3 -m pip install "git+https://github.com/YuxiaoMa66/antigravity-mission-control.git@v0.4.2rc1"`。稳定版仍是 v0.4.1，`@latest` 不会移动。验证：Python 与 npm 测试套件与拆分前的结果逐项一致（46 与 12 个测试），除两处为 worker 启动指明 `cli.py` 的代码外，所有顶层定义与原文件的 AST 等价，并且在隐藏源码包的情况下，安装后的 wheel 通过了运行时测试（含后台任务）。
