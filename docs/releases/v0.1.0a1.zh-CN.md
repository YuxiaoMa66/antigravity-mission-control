# v0.1.0a1 — 任务控制台上线

第一个公开 Alpha 候选版本。

## 主要更新

- 带签名、会过期的批准清单，绑定精确模型、工作区、prompt 哈希、模式和权限配置。
- 前台与后台 worker 共用操作系统级原子编辑锁。
- TERM 宽限等待与 KILL 升级后的取消确认。
- 脱敏的实时额度终端界面和 JSON Schema。
- Python 提供可恢复的 Codex Skill 安装、更新和卸载。
- 无第三方依赖的 npm bootstrap，带中英文终端界面。
- README、安装、参考和发布文档全部中英双语。

## 验证

全部 Python 与 Node 黑盒测试使用 fake AGY，并隔离 HOME、工作区和状态目录；另有只读 smoke 验证本机 AGY CLI 和实时 `/usage` 契约。

## Alpha 限制

- 为迁移仍保留旧布尔批准参数。
- HMAC 证明本地清单完整性，不证明真人身份。
- 仅支持 macOS 和 Linux；编辑锁依赖 `flock`。
- 不宣称通过统计或安全认证。
