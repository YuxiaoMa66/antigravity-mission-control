# v0.1.0a3: Idempotent setup and a clearer flight deck

The third Alpha fixes a real first-run collision found by installing over an existing managed Skill and makes the working CLI surfaces visible before users install.

## Changes

- `install` now follows the recoverable update path when the existing target is managed by Mission Control.
- An unmanaged target collision is rejected before AGY or the private Python runtime is changed.
- Added regression tests for both collision paths.
- Added four consistent interface captures: guided installation, live quota, bound approvals and background jobs.
- Expanded the English and Chinese READMEs with the interface gallery and an explicit sanitization note.

## Evidence

The defect was reproduced on a real alpha.2 installation: the Python runtime succeeded, the existing Skill caused an exit, and the launcher was never created. Running `update` recovered the installation with a backup. The alpha.3 tests cover that exact ordering failure.

The interface assets are deterministic SVG renders of real CLI formats. Paths, signatures, job IDs and quota values are examples; they do not expose account identity or OAuth material.
