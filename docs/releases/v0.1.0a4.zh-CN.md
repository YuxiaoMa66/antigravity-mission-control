# v0.1.0a4：把 GitHub 页面直接交给 Agent

第四个 Alpha 把 GitHub 页面变成可以直接复制给 Agent 的安装交接说明，并让用户在任何 worker 启动前看清阵容选择。

## 变化

- 增加可直接复制的 prompt，要求 Agent 阅读仓库、检查 AGY、展示精确目标、等待确认、安装 Mission Control 并运行 doctor。
- 增加清晰的 A/B/C 对照，说明团队设计、适用任务、额度、耗时和审核独立性。
- 规定统一的阵容选择格式，包含精确模型、角色、文件范围和执行模式。
- 规定统一的修改确认格式，对比已批准值与拟修改值，解释原因和影响，并暂停受影响条目。
- 在中英文 README 图集中增加对应的阵容选择和修改确认界面图。

## 一致性边界

图片展示安装后 collaboration protocol 要求的字段顺序。图中的模型名称标明为当前目录示例；实际提案会调用 `agy-mc models`，展示本次会话可用的精确 slug。

workspace trust 与 unrestricted 权限仍需分别批准。接受阵容或阵容修改不会自动授予其中任何一项。
