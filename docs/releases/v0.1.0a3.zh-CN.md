# v0.1.0a3：幂等安装与更完整的控制台展示

第三个 Alpha 修复了在已有受管 Skill 上安装时发现的真实冲突，并让用户在安装前就能看到主要 CLI 界面。

## 变化

- 目标中已有 Mission Control 管理的 Skill 时，`install` 自动采用可恢复的更新路径。
- 未受管目标发生冲突时，在修改 AGY 或私有 Python runtime 前停止。
- 为两种目标冲突增加回归测试。
- 增加四张统一的界面图：引导安装、实时额度、绑定批准和后台任务。
- 中英文 README 同步加入界面图集和明确的脱敏说明。

## 证据

alpha.2 的真实安装复现了问题：Python runtime 安装成功，已有 Skill 导致流程退出，启动器没有创建。使用 `update` 后安装得到恢复并留下备份。alpha.3 测试覆盖了这条精确的顺序缺陷。

界面资产是根据真实 CLI 格式确定性生成的 SVG。路径、签名、任务 ID 和额度数字均为示例，不包含账户身份或 OAuth 材料。
