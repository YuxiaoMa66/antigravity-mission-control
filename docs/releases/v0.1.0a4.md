# v0.1.0a4: Give the page to your agent

The fourth Alpha turns the GitHub page into a copy-ready Agent setup handoff and makes roster selection visible before any worker starts.

## Changes

- Added a copy-ready prompt that asks an Agent to inspect the repository, verify AGY, show exact targets, request confirmation, install Mission Control and run doctor.
- Added a clear A/B/C comparison covering team design, suitable tasks, quota, latency and reviewer independence.
- Defined one required roster-selection format with exact models, roles, filesystem scope and execution profiles.
- Defined one required change-confirmation format that compares approved and proposed values, explains the reason and impact, and pauses the affected entry.
- Added matching roster-selection and roster-change images to both README galleries.

## Consistency boundary

The images illustrate the field order required by the installed collaboration protocol. Model names in the image use a labeled current-catalog example; real proposals call `agy-mc models` and show the exact slugs available in that session.

Workspace trust and unrestricted permissions remain separate approvals. Accepting a roster or roster change does not grant either one.
