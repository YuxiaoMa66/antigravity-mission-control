# v0.4.2rc2：模块拆分的守卫修复（预发布）

v0.4.2rc1 引入的 `cli.py` 模块拆分的第二个候选版本。对 rc1 的审核发现了几处守卫漏洞，本版本将其补上。路由与 Skill 文本均不变。npm 版本号：`0.4.2-rc.2`。

- 失败的后台 worker 不会再被报告为成功。此前，只要 AGY 的 stderr 中出现该状态文字，一次失败的运行（例如权限被 soft-deny）就会被标记为 `done_with_warnings` 并以 0 退出。
- 宽泛目录不能再作为工作区。home 目录的上级（例如 `/Users`）以及系统临时目录根，不能再被信任、批准或用于运行；请改用其中的具体项目目录。
- 启动进程提前退出时，后台任务不会再卡在 `starting`；启动过程中发出的取消会优先生效。
- `agy-mc skill uninstall` 现在会拒绝不是由 agy-mc 安装的目录，除非传入 `--force`，与安装和更新的既有行为一致。npm `uninstall` 会在做任何修改前检查所有目标，因此不会中途停下。

试用方式：`npx antigravity-mission-control@next install`，或 `python3 -m pip install "git+https://github.com/YuxiaoMa66/antigravity-mission-control.git@v0.4.2rc2"`。稳定版仍是 v0.4.1，`@latest` 不会移动。验证：51 个 Python 测试与 13 个 npm 测试；每项修复都新增了修复前会失败的回归测试。
