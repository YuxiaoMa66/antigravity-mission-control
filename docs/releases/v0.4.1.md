# v0.4.1: Hardening for Codex and Claude Code

A patch release for v0.4.0. It fixes two npm installer edge cases and tightens the Claude Code host notes. Routing, signed approvals and worker execution are unchanged.

- `npx antigravity-mission-control uninstall` removes the managed runtime and CLI link again when no managed Skill is found. v0.4.0 stopped with "No supported host detected" and left them in place.
- `status` is no longer blocked by an unrelated host's config directory that is a symlink outside HOME.
- The Claude Code host notes now suggest allow rules only for read-only subcommands (`usage`, `doctor`, `models`, `policy`, `select`, `status`, `result`, `wait`). The earlier `Bash(agy-mc *)` suggestion would also have auto-approved `approve`, `run` and `workspace --grant`. Each `agy-mc` command should run as its own Bash call, and sandboxed state writes belong in `sandbox.filesystem.allowWrite`.

Upgrade with `npx antigravity-mission-control@latest update`, then start a new Claude Code session or restart Codex. Validation: Python and npm suites, bundled Skill synchronization, interface-asset checks, package dry-run, and the two regressions reproduced against the published 0.4.0 package before fixing.
