# v0.1.0a5：策略生效与工作区证据

查额度和管理已有任务现在直接进入对应命令。新任务保留默认 A/B/C 流程；用户选择 balanced 后可以省略三套展示。

新签名审批绑定实际策略。strict 新任务增加 `--three-rosters-presented` 声明；纠错用 `approve --correction-of <job-id>`，普通范围内追问用 `--follow-up-of <job-id>`。两者保留父任务分工和策略；记录链中的第三次纠错被拒绝，普通追问保留计数。

运行在工作区外保存私有 Git 前后快照、变更路径指纹、diff 哈希及原始/实际派发提示词哈希；worker 获得已有用户改动的有界摘要。后台结果明确保留编排者的验收责任，模型执行完成不等于任务验收通过。

兼容边界：旧审批清单和布尔参数继续可用，但不具备新策略链约束。确认参数是声明，不能证明人类真实同意；快照有明确限制，不执行文件归属控制，也不代替 diff 检查。纠错限制针对记录链，不是全局调用预算。

验证：29 项 Python 测试、8 项 npm 安装器测试、技能格式校验、wheel 检查和使用 fake AGY 的已安装入口 smoke test。未进行真实 worker 质量基准。

Python/Git：`0.1.0a5` / `v0.1.0a5`；npm：`0.1.0-alpha.5`，预发布通道 `next`。
