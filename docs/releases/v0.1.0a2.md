# v0.1.0a2: Bring your own Gemini

The second Alpha sharpens the project's reason for existing and makes first-time setup less awkward.

## Changes

- Added `--install-agy` for users who do not have Antigravity CLI yet.
- Downloads Google's official installer to a private temporary file, checks the response, runs it without shell interpolation, and removes the temporary copy.
- Keeps AGY installation as a separate explicit choice in non-interactive environments.
- Explains the first-run `agy` Google sign-in without reading or copying OAuth state.
- Rewrote the bilingual project introduction: Codex manages scope and acceptance while AGY workers handle implementation.

## Validation boundary

The installer verifies that `agy --version` works after installation. The user completes Google sign-in through AGY's own interactive interface.
