# v0.4.0 visual direction

This release keeps the v0.3.0 operational-evidence visual system unchanged. Only release identity and host wording change.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels are updated to `0.4.0`; the install plate now shows host auto-detection (`codex / claude`) and acceptance is attributed to the host agent instead of a single product.

Assets:

- `assets/release-v0.4.0.svg` is the current GitHub cover.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.4.0 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
