# v0.6.0 visual direction

This stable release keeps the visual system unchanged. Only the release identity changes.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels are updated to `0.6.0`.

Assets:

- `assets/release-v0.6.0.svg` is the current GitHub cover.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.6.0 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
