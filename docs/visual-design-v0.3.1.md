# v0.3.1 visual direction

This patch release keeps the v0.3.0 operational-evidence visual system unchanged while versioning the current release assets and examples consistently.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels, install commands and route examples are updated to `0.3.1` so the GitHub README and npm package do not mix release identities.

The graphite, warm-paper, safety-orange and sage palette remains the same. The design change is intentionally limited to release identity and documentation accuracy; no new visual component or dependency is introduced.

Assets:

- `assets/release-v0.3.1.svg` is the current GitHub cover.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.3.1 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
