# v0.4.2rc3 visual direction

This pre-release keeps the v0.4.1, v0.4.2rc1 and v0.4.2rc2 visual system unchanged. Only the release identity changes.

The cover and interface plates remain deterministic SVG illustrations, not live screenshots. Version labels are updated to `0.4.2rc3`.

Assets:

- `assets/release-v0.4.2rc3.svg` is the current GitHub cover and is marked as a pre-release.
- `assets/terminal-preview.svg` and the eight files under `assets/interfaces/` use v0.4.2rc3 examples.
- `assets/logo/mission-control.svg` remains unchanged.

All model names and command outputs in the illustrations are examples. They are not live screenshots or additional acceptance evidence.
